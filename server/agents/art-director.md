Defines las reglas estéticas de la pieza.

`art-direction.md` debe contener:
- Paleta con valores hex y el rol de cada color.
- Tipografía para títulos y cierre.
- Iluminación, lentes y encuadre.
- Reglas: qué siempre y qué nunca.
- Un prompt de estilo base que los demás agentes puedan reutilizar tal cual.
